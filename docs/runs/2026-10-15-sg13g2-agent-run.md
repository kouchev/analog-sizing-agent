Derivation:

- Cc = cc_ratio*CL = 1*2p = 2 pF
- I5 = SR*Cc = 45 V/us * 2 pF = 90 uA
- S3 = I5/(kp*(VDD-Vin,max-|Vthp|+Vthn)^2) = 53.4  (headroom 0.153 V)
- gm1 = 2*pi*GBW*Cc = 628.3 uS;  S1 = gm1^2/(kn*I5) = 16.1
- VDS5,sat = Vin,min - sqrt(I5/(kn*S1)) - Vthn = 0.380 V;  S5 = 2*I5/(kn*VDS5^2) = 4.58
- gm6 = p2_ratio*2*pi*GBW*CL = 2199 uS;  S6 = S4*gm6/gm4 = 199;  I6 = gm6^2/(2*kp*S6) = 168 uA
- S7 = S5*I6/I5 = 8.53
- Rz = rz_ratio/gm6 = 1.59 kOhm;  LHP zero z = 1/(2*pi*Cc*(Rz-1/gm6)) = 70 MHz
- Av = gm1/(gds2+gds4) * gm6/(gds6+gds7) = 62.9 dB
- GBW = gm1/(2*pi*Cc) = 50 MHz;  p2 = gm6/(2*pi*CL) = 175 MHz;  PM = 90 - atan(GBW/p2) + atan(GBW/z) = 109.6 deg
- P = VDD*(Ibias + I5 + I6) = 0.417 mW

## Agent's final answer

Recommended design: D17 (IHP SG13G2 typical corner, ngspice 45.2). Agent: Claude acting in-conversation (no API), following the equation-first methodology.

Knobs: cc_ratio 1.0, p2_ratio 3.5, rz_ratio 3.5, sr 50 V/us, vin_min 0.78 V, vin_max 0.95 V, L1 = L5 = 3.5 um, L3 = L6 = 0.7 um.

All transistors saturated (M2 has the least margin, about 0.12 V above Vdsat).

Passes: 12 simulations of 15, 18 calculated designs, 5 recalibrations.

Where the equations are accurate after back-annotation: power (within 1-3 %), gain (within 1-2.5 dB once lambda is measured at the lengths in use).
Where they are not: phase margin (no third pole Rz*C1, no mirror pole, so predictions above 90 deg are meaningless), GBW (first-stage capacitance missing, 5-35 % optimistic), lambda (lambda*L is not constant in SG13G2: 0.24 um/V at 1 um, 0.78 um/V at 3.5 um for NMOS).
The decisive knob was rz_ratio: at Rz = 1/gm6 the best design reached 52 deg / 43 MHz; with rz_ratio 3.5 the same sizes reach about 70 deg / 55 MHz.
Gain margin is thin. More gain needs a structural change (cascode, or separate L for M3 and M6), which the current knob set cannot express.

D17 sizes: w1 50.74, l1 3.5, w3 41.56, l3 0.7, w5 19.39, l5 3.5, w6 139.5, l6 0.7, w7 32.53, ibias 100, cc 2, rz 1.592 (W, L in um; ibias in uA; cc in pF; rz in kOhm).
D18 (SR 45) also meets the spec at 0.427 mW but with only 2.5 % GBW margin and +0.1 dB more gain, so D17 is recommended.
